# EarthBeat Accessibility

EarthBeat is designed toward **WCAG 2.2 AA** practices. This document lists what is implemented, how it was checked, and what has not yet been validated. It does not claim WCAG conformance.

## Intended users

- Blind and low-vision students age 12+ and the educators who teach them
- Curious members of the public, including people who prefer listening or reading to watching
- Anyone exploring Earth data on a phone, tablet or computer, with or without sound

## Implemented features

### Structure and semantics
- One `<h1>`, ordered `<h2>`/`<h3>` outline; `header`, `nav` (“Main”), `main`, `section`, `aside` and `footer` landmarks.
- “Skip to the listening room” link is the first focusable element.
- Native `<button>`, `<input type="range">`, radio buttons and checkboxes; every control has a visible text label or an accessible name.
- Decorative SVG and the hero illustration are `aria-hidden`. The activity chart has a text description; its click-to-seek is duplicated by the keyboard-accessible seek slider.
- The video has a written description (`aria-describedby`) of what it shows, its data period and that it has no soundtrack.

### Keyboard map

| Key | Action |
|---|---|
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | Move between controls |
| <kbd>Space</kbd> / <kbd>Enter</kbd> | Activate the focused button (Play/Pause, Restart, Stop sound, Mute, guided moments) |
| Arrow keys | Move the seek slider (1 s steps; Page Up/Down for larger jumps), volume slider, or speed choice |
| <kbd>Esc</kbd> | Stop sound and pause, from anywhere on the page |

No single-letter shortcuts are used, so screen-reader and browser commands are not overridden.

### Screen readers
- **Live summary** (`aria-live="polite"`): a sentence such as “Ten-day roving window, 2017 to 2023. Dense activity, increasing, in the upper left of the frame, concentrated.” at most every 4 seconds while playing — never per frame. A checkbox turns announcements off.
- **Status announcements** (`role="status"`): playing, paused, position after seeking (“At 1 minute 35 seconds”), muted/sound on, sound stopped, finished, page hidden, and sound unavailable. Errors use `role="alert"`.
- Seek and volume sliders expose spoken values (“1 minute 35 seconds of 3 minutes 36 seconds”, “60 percent”).
- Every legend row states what is measured, what it sounds like, what it tells you and what it does not mean, plus a current value in words or percent.

### Vision and motion
- Dark theme with body text at 11–17:1 contrast; accent colors (cyan, yellow, coral) ≥ 7.5:1 on panels (computed from the CSS tokens).
- High-contrast theme (pure black, white lines and text) toggled in the header.
- 3 px yellow focus outline with offset on every focusable element.
- States use text and shape, not color alone (status text, play/pause icon shapes, pressed state on Mute).
- The sticky header is disabled below 1000 px width or 560 px height so it cannot cover focused content on phones or when zoomed.
- Reduced motion follows the system setting and can be toggled; it disables the hero animation and smooth scrolling. No flashing content is generated by EarthBeat (the NASA video itself contains small twinkling points, not full-screen flashes).

### Sound
- No autoplay. The `AudioContext` is created only after the user presses Play or Start listening.
- Default volume 60% of a limited ceiling; 70 Hz high-pass (no sub-bass), highest note 880 Hz, limiter, ±0.8 maximum stereo position.
- Volume, Mute, Stop sound (<kbd>Esc</kbd>), Gentle sound mode, and per-layer toggles.
- Headphones are suggested only as optional (for stereo position).
- Without sound, the live summary, legend values and activity timeline still convey every mapping.

## How it was checked (2026-11-14)

| Check | Tool / method | Result |
|---|---|---|
| Automated rules, default and high-contrast themes | axe-core 4.10.3 via Playwright (WCAG 2.0/2.1/2.2 A & AA tags) | 0 violations, 29 rules passed, 2 rules “needs review” per theme |
| “Needs review”: color contrast over gradients | Manual computation of contrast for each text/background token pair | All text ≥ 7.5:1 (lowest: coral on panel) |
| “Needs review”: video captions | Manual | The video has no audio track; it is described in text, so captions are not applicable |
| Accessible names, landmarks, heading count, live-region settings | Vitest + Testing Library component tests | Pass |
| Keyboard path: skip link first, Play reachable by Tab | Playwright, Chrome | Pass |
| <kbd>Esc</kbd> stops sound | Component test and Playwright | Pass |
| Layout at 360×800, 768×1024, 1440×900, and 720 px (≈ 200% zoom of 1440) | Playwright: no horizontal overflow, Play visible | Pass |
| Reduced motion system preference | Playwright (`reducedMotion: 'reduce'`) | Pass — animation disabled |
| Video failure and slow network | Playwright (blocked / delayed request) | Readable error with Try again; loading state shown |
| Visual review of screenshots (desktop, mobile, high contrast) | Manual | Defects fixed: header covering content on phones, centered link text, decorative bars not rendering |

## Known limitations and future validation

- **No testing with blind or low-vision users has taken place.** Co-design and testing sessions with blind and low-vision students and teachers of the visually impaired are the most important next step.
- Not yet tested with VoiceOver, NVDA or JAWS end to end; structure was verified programmatically only.
- Not yet tested on iOS Safari or Android devices; layout was tested in desktop Chrome at phone widths.
- The NASA video itself has small on-screen text (date, season wheel) that EarthBeat does not re-voice frame by frame; the chapter names and guided moments give the period instead.
- Seasonal and geographic context is inferred from the picture; EarthBeat does not name continents in its live summary because the globe rotates and naming would require geographic data not in the frames.
